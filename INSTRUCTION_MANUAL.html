Rotten Tomatoes Data Visualization

Project Instruction Manual

A comprehensive guide for setup, development, and deployment

Author: Miayunique South

1. Project Overview

1.1 What Is This Project?

This is an interactive data visualization dashboard that analyzes Rotten Tomatoes movie ratings data. The project presents multiple D3.js-powered visualizations exploring relationships between critic scores, audience ratings, box office performance, genre trends, and director-actor collaborations.

1.2 Key Features

  • Interactive Scatterplot: Compare critics vs. audience agreement with filtering by genre, studio, and rating
  • Choropleth Map: Visualize worldwide weekend box office performance
  • Trend Analysis: Track Tomatometer scores by rating classification over time
  • Movie Search: Interactive search
  • Director Tree: Explore director-actor collaboration networks
No Build Process Required: This is a static web project. There are no npm dependencies, no compilation steps, and no build tools needed. Simply serve the files and open in a browser.

2. Prerequisites

2.1 Required Software

  • Web Browser: Chrome (recommended), Firefox, Safari, or Edge
  • Local Web Server: One of the following options:
    • Python 3.x (comes with macOS/Linux)
    • Node.js with npx
    • VS Code with Live Server extension
    • Any HTTP server software
  • Text Editor: VS Code, Sublime Text, or any code editor (for modifications)

3. Quick Start Guide

3.1 Step-by-Step Setup

Step 1: Get the Project Files

# Clone from repository (if using Git)
git clone https://github.com/msouth-code/dataviz_finalproject.git
cd dataviz_finalproject

# Or simply copy the project folder to your computer

Step 2: Start a Local Server

Choose ONE of the following methods:

Option A: Python (Recommended for macOS/Linux)

# Navigate to project folder
cd /path/to/dataviz_finalproject

# Start server on port 8000
python -m http.server 8000

# You should see: Serving HTTP on :: port 8000 ...

Option B: Node.js

# Navigate to project folder
cd /path/to/dataviz_finalproject

# Run http-server (no installation needed with npx)
npx http-server

Option C: VS Code Live Server

  1. Open the project folder in VS Code
  2. Install the "Live Server" extension (if not already installed)
  3. Right-click on index.html
  4. Select "Open with Live Server"

Step 3: Open in Browser

# Open your browser and navigate to:
http://localhost:8000
Success! You should see the main dashboard with five visualization tiles: No Filter, Battle of Box Office, Over the Years, Search Party, and Director's Choice.

3.2 Quick Start Checklist

  • Project files downloaded/cloned
  • Terminal/command prompt open in project folder
  • Local server running (Python, Node, or VS Code)
  • Browser open at localhost:8000
  • Main dashboard visible with 5 tiles

5. Data Documentation

5.1 Primary Dataset: movieratings.csv

Contains 7,727 movies with the following columns:

Column Type Description
movie_titleStringTitle of the movie
movie_infoStringSynopsis/description
critics_consensusStringCritics' summary review
ratingStringMPAA rating (G, PG, PG-13, R, etc.)
genreStringGenre(s), comma-separated
directorsStringDirector name(s)
writersStringWriter name(s)
castStringCast members, comma-separated
in_theaters_dateDateTheatrical release date (YYYY-MM-DD)
on_streaming_dateDateStreaming release date
runtime_in_minutesIntegerMovie length in minutes
studio_nameStringProduction studio
tomatometer_statusStringFresh, Certified Fresh, or Rotten
tomatometer_ratingIntegerCritics score (0-100)
tomatometer_countIntegerNumber of critic reviews
audience_ratingIntegerAudience score (0-100)
audience_countIntegerNumber of audience ratings

6. Deployment

6.1 GitHub Pages (Recommended)

This project is configured for GitHub Pages deployment:

  1. Push code to a GitHub repository
  2. Go to repository Settings → Pages
  3. Select "Deploy from a branch"
  4. Choose main branch and / (root) folder
  5. Click Save
  6. Access at: https://username.github.io/repository-name
